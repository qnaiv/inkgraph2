# 敵ブキを結果画面ボードのアイコンで見分ける（#17 続き）調査メモ

目的：「その敵ブキがいた全試合」を母数にした勝率を出す。D47 では母数を「そのブキにやられた試合」にしていた（HUD アイコンでは見分けられなかったため）。

## 1. 方針
- 結果画面ボード（背景が黒で一定）の敵 4 枠のブキアイコンを使う。HUD と違い、チーム色の影響を受けず、試合をまたいで同じ絵がほぼ同じ画素で出る。
- アイコンに名前テキストは無いので、名前は **同じ試合のデスカメ** から付ける：
  デスカメの吹き出し「<ブキ名> で やられた!」の上に出る倒した相手のアイコンを、その試合のボードの敵 4 枠と照合し、一番似た枠にそのブキ名を付ける。
- 名前付きのボードアイコンを見本（ライブラリ）にして、他の試合の敵枠を照合する。見本と十分似ていなければ「不明」。

## 2. 手元の結果（12 試合、2026-10-24 夜）
### 2.1 ボードアイコンどうしの類似度（グレーの NCC、内側を切り出して ±数 px のずれを許容）
- 1080p：同じブキ 0.95 以上（103 組）、0.90〜0.95 は 0 組、派生（札の違い）0.85〜0.90、それ以外 0.85 未満。
- 720p（アプリの解析解像度）：同じブキ 0.977〜1.0、違うブキの最大は 4Kスコープ×リッター4K 0.989、次がヒーローシューター レプリカ×わかばシューター 0.90。
- **4Kスコープとリッター4K はボードの絵ではほぼ区別できない**（スコープ部分が小さい）。→ この 2 つは「不明」にする（間違えるより不明）。

### 2.2 デスカメのアイコン → ボードの枠（名前付け）
- 吹き出しのアイコンはボードの約 2.3 倍（1080p）。倍率 1.9〜2.7 で照合、吹き出しが出ている最大 16 フレームの最大値。
- 54 件（吹き出しのあるデス）のうち、score 0.68 以上かつ 2 位との差 0.15 以上の「確信あり」は 37 件。
- 確信ありの 37 件で：同じ名前が別の枠に付いたこと 0、1 つの枠に別の名前が付いたこと 0。→ 23 枠に名前が付いた。
- 確信なしの 17 件の多くはスペシャル（カニタンク・ウルトラハンコ・サメライド・ナイスダマ・ジェットパック）で倒されたデス（吹き出しにスペシャルのアイコンが出るので、ボードのメインブキと合わない＝正しく「不明」）。

### 2.3 試合をまたいだ照合（試合ごとに外す）
- 名前付き 23 枠を、その試合以外の見本だけで照合（しきい値 0.93）：正しい 8、取り違え 2（4Kスコープ↔リッター4K）、不明 13（その試合にしか出ないブキ）。
- 4Kスコープ／リッター4K を「不明」扱いにすると取り違え 0。
- 名前付き枠どうしの全組（試合が違うもの 235 組）：同名で 0.93 以上 4 組・同名で未満 0 組・別名で 0.93 以上 1 組（4K の組）。
- 全 48 敵枠のうち名前が付く枠：31（その試合のデスカメ由来 23 ＋ 他試合の見本由来 8、4K の 2 枠は不明）。

## 3. 正解・素材
- labels/enemy_icon/board_icon_truth.json：試合ごとの敵 4 枠の名前（上の方法で付いたもののみ、他は null）と、デスごとの照合結果。
- labels/enemy_icon/boards/*.png：12 試合の結果画面（720p）のアイコン列（x680〜770・y250〜680）の切り出し。
- tools/research/enemy_icon/：調査に使った Python（board_dump → icons → sim/sim720 → dcicon → match → evalx）。
