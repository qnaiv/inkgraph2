## 背景・目的
スプラトゥーン3の自分のプレーを振り返るため、録画から自分の成績と試合展開を自動で抽出する。最終的には「抑え／打開、カウント差などの状況の中で、どのデス・キルが勝敗に効いたか」を分析したい。

## 録画と転送
- OBSで1080p MKV録画
- `autosplit.py` で試合ごとに切り出し → Googleドライブ「grok用」フォルダへ（1ファイル100MB制限のため95MB未満に分割）→ `join_parts.py` で結合

## 検出の方針
- OCR・YOLO・有料APIは使わない。1280x720に正規化し、固定座標のHUD切り抜き＋テンプレート照合＋小さな分類器（ロジスティック回帰、数字分類器）
- 自分のデス：十字キー付近の「やられた」表示
- 味方/敵のデス：HUDイカアイコン分類＋リスポーンマップのネームプレート
- スペシャル：ゲージリングの色（オレンジ=溜め中、白=満タン）
- リザルト：WIN/LOSEテンプレート、モード/ステージはラベル付き切り抜きライブラリ、数字は数字分類器
- ヤグラ：「のこりNN」バッジの数字分類＋ハフ円でヤグラ位置と保持チーム

## 既知の問題
- 試合1序盤（0:32〜1:35）の自チームバッジが読めない（薄いオレンジで字が分割できない）
- 数字0/1/6/9の学習データが少ない
- マップのネームプレート追加が1080pで誤検出することがある
- HUDスロット→プレイヤー名の対応付けは未実装（優先度低で中止）
- 勝率モデルの重みは手設定（試合数不足）
