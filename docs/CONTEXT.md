## 背景・目的
スプラトゥーン3の自分のプレーを振り返るため、録画から自分の成績と試合展開を自動で抽出する。最終的には「抑え／打開、カウント差などの状況の中で、どのデス・キルが勝敗に効いたか」を分析したい。

## 録画と転送
- OBSで1080p MKV録画
- `autosplit.py` で試合ごとに切り出し → Googleドライブ「grok用」フォルダへ（1ファイル100MB制限のため95MB未満に分割）→ `join_parts.py` で結合

## 検出の方針
- OCR・YOLO・有料APIは使わない。1280x720に正規化し、固定座標のHUD切り抜き＋テンプレート照合＋小さな分類器（ロジスティック回帰、数字分類器）
- 自分のデス：十字キー付近の「やられた」表示
- 味方/敵のデス：HUDイカアイコン分類＋リスポーンマップのネームプレート
- スペシャル：ゲージリングの色（オレンジ=溜め中、白=満タン）
- リザルト：WIN/LOSEテンプレート、モード/ステージはラベル付き切り抜きライブラリ、数字は数字分類器
- ヤグラ：「のこりNN」バッジの数字分類＋ハフ円でヤグラ位置と保持チーム

## ブラウザ版（web/）
- Vite＋素のES Modules。バックエンドなし。Web Workerで5フレーム／秒（1080pで1フレーム約10ミリ秒）。試合と録画はIndexedDBに保存（D15）。
- ページ：ライブ分析、試合一覧、試合の詳細・確認、傾向分析。使い方は [README.md](../README.md) を参照。
- フィードバックの流れ（D16）：確認モードで正誤を付ける → 「フィードバック書き出し」でzip → Googleドライブ「grok用」へ → ボックスで `python tools/ingest_feedback.py FEEDBACK.zip --apply`。
- コードの実装はAntigravity CLI（agy）が担当し、ログは `docs/AGY_LOG.md`（D17）。

## 既知の問題
- 試合1序盤（0:32〜1:35）の自チームバッジが読めない（薄いオレンジで字が分割できない）
- 数字0/1/6/9の学習データ不足（D32でf1/f2から326件追加し計2,428件へ拡充。LOMO精度は6が0%→29.3%、9が0%→46.7%に改善したが、9は30件、6は116件と依然他数字より少なく改善余地あり。詳細は [docs/digit-samples.md](digit-samples.md) 参照）
- マップのネームプレート追加が1080pで誤検出することがある
- HUDスロット→プレイヤー名の対応付けは未実装（優先度低で中止）
- 勝率モデルの重みは手設定（試合数不足）
- ブラウザ版のヤグラ位置検出（HoughCirclesの代替）はPythonとの一致率が約79%
