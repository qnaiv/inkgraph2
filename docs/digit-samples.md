# ガチヤグラ カウント数字サンプル（TC Badge Digits）拡充記録

ガチヤグラの「のこり NN」HUDバッジから抽出される数字（0〜9）分類器データセット（`templates/res_digits/tc_badge_digits.npz`）の追加採取・検証記録。

## 1. 採取方法とデータソース

- **正解ラベルファイル**: `templates/res_digits/tc_badge_labels.json`（合計 347 フレーム）
  - Grok が動画から抽出したコンタクトシート（`out/digit_harvest/`）を目視確認して作成・検証したグラウンドトゥルースラベル。
- **対象動画と時刻**:
  - `f1`: `/workspace/inkgraph/raw/full_matches/full_match01.mp4`
    - バトル区間: [61.0, 191.0] 秒
    - チーム色推定（`detect.team_hues`）: `own=39, enemy=155`（harvest 時と同一）
    - 時刻: 動画内経過秒（そのまま）
  - `f2`: `/workspace/inkgraph/raw/full_matches/full_match02.mp4`
    - バトル区間: [20.0, 322.0] 秒（`full_segments.json` の通し時刻 440.0〜742.0 秒から開始時刻 420.0 秒を引いた動画内秒）
    - チーム色推定（`detect.team_hues`）: `own=113, enemy=5`
    - 時刻: 通し時刻から 420.0 秒を引いた動画内秒
- **除外した読取不能フレーム（計6フレーム）**:
  - `f1 enemy`: `t=151.0`（1フレーム）
  - `f2 own`: `t=98.0`, `t=150.0`（2フレーム）
  - `f2 enemy`: `t=88.0`, `t=139.0`, `t=270.0`（3フレーム）
  - ※上記6フレームは目視段階で遮蔽・アニメーション破綻などにより読取不能と判断され除外済み。

## 2. フレーム抽出・キャップ処理

- **フレーム取得**: 対象時刻に最も近いフレームをピンポイントでシーク取得（`step`走査を行わず高速処理）。
- **特徴量算出**: `tower.badges` → `tower.glyphs`（2文字） → `tower.feat`（97次元: 8x12の正規化画素 + アスペクト比）。
- **キャップ処理（Cap）**:
  - 同一カウントの静止フレームによる偏りを防ぐため、`(match_id, side, label)` ごとに最大 **20** フレームを均等間隔（`np.linspace`）で選択。
  - ユニークグループ数: 84 グループ
  - キャップ超過グループ（3グループ）:
    - `('f1', 'own', '50')`: 48 → 20 件
    - `('f2', 'own', '36')`: 158 → 20 件
    - `('f2', 'enemy', '77')`: 38 → 20 件
  - キャップ前フレーム数: 347 件（694 glyphs）
  - キャップ後フレーム数: 163 件（326 glyphs: f1=148, f2=178）

## 6. 残課題・考察

1. **Digit 9 のデータ量不足**:
   - 8件から30件へ拡充され LOMO 精度も 0% → 46.67% と向上したが、依然として他数字（100〜400件台）と比較して絶対数が最も少ない。今後の追加マッチで 90 番台・19 番台・9 カウント等のサンプル補強が望まれる。
2. **Digit 6 の精度改善余地**:
   - 01 単独依存（68件）から f1(+20)/f2(+28) を加えて 116件まで拡充、LOMO 0% から 29.31% へ向上したが、未だ約3割の認識率にとどまる。バッジの背景インク色やグラデーション影響に対する頑健化が必要。
3. **Digit 0 の LOMO 低下要因**:
   - 追加前 96.08% から 81.20% に低下。新データ（f1/f2）の 0 はバッジ境界や十の位／一の位でのアスペクト比差異があり、他数字（8や6等）との誤認パターンを分析して前処理（二値化閾値等）の見直しを検討。
4. **Digit 2 の汎化性**:
   - 旧データセットでは 02 にしか含まれず LOMO 0% だったが、f1/f2 で少量追加されたことで 50.31% まで改善。さらにサンプルを蓄積することで安定認識が期待できる。
