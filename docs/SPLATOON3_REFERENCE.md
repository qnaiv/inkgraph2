# スプラトゥーン3 の対戦ステージとブキ(スプラ3 だけ)

**ここに載っているのは スプラトゥーン3 のものだけ。** 初代・2 にしか無いステージやブキは混ぜない。
ステージ名・ブキ名・テンプレート・見本・テストデータを足すときは、先にこの表で名前が合うか確かめる。

- 取得日: 2026-10-31
- 出どころ: スプラトゥーン3 のゲーム内テキスト(日本語)を公開している Leanny 氏のデータ `https://leanny.github.io/splat3/data/language/JPja_unicode.json`(`CommonMsg/VS/VSStageName`, `CommonMsg/Weapon/WeaponName_Main`, `CommonMsg/Weapon/WeaponTypeName`)。ステージ数はコミュニティ Wiki(wikiwiki.jp/splatoon3mix の「ステージ」、Ver.10.0.0 時点で 25)とも一致した。
- 新しいシーズンでステージ・ブキが増えたら、同じデータを取り直して、この表とコードを更新する。

## いまのコードとのズレ(2026-10-31 時点)

### `web/src/stage_lib.js` の `STAGES`(23)
- 登録済み(D106): コンブトラック、マンタマリア号は選択肢に足した。見本（画像）はまだ無いので、読み取りは出会って名前を付けてから。

### `web/src/core/weapons.js` の `WEAPONS`
- スプラ3 に無い名前(**スプラ2 のブキが混ざっている**、5): N-ZAP83、プロモデラーPG、ボールドマーカー7、H3リールガンチェリー、モップリンカスタム。ただし、これは「ゲームのデータに無い」ことしか確かめていない。消す前に、観測済みのブキ名(`enemy_icon`・`killer` の見本)に使われていないか見る。
- 未登録のスプラ3 のブキ(27): プロモデラー彩(シューター)、.96ガロン爪(シューター)、ジェットスイーパーCOBR(シューター)、スプラシューター煌(シューター)、H3リールガンSNAK(シューター)、L3リールガン箔(シューター)、ホットブラスター艶(ブラスター)、カーボンローラーANGL(ローラー)、ダイナモローラー冥(ローラー)、ワイドローラー惑(ローラー)、フィンセントBRNZ(フデ)、ホクサイ彗(フデ)、スプラスコープFRST(チャージャー)、スプラチャージャーFRST(チャージャー)、ヒッセンASH(スロッシャー)、モップリン角(スロッシャー)、ハイドラント圧(スピナー)、スプラスピナーPYTN(スピナー)、デュアルスイーパー蹄(マニューバー)、スプラマニューバー耀(マニューバー)、スパッタリーOWL(マニューバー)、スパイガジェット繚(シェルター)、キャンピングシェルターCREM(シェルター)、トライストリンガー燈(ストリンガー)、LACT-450MILK(ストリンガー)、ドライブワイパーRUST(ワイパー)、ジムワイパー封(ワイパー)。新しい種類の名前(漢字 1 字や英字の接尾辞)が付いたもの。
