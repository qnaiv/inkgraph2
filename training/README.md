# training

確認画面で付けた正解データと、その前後の画像（学習用）。`inbox/` に上げた zip から自動で作られます（`tools/archive_training.py`）。

- `index.json`: 取り込んだバッチの一覧（試合数・画像数・容量）と、画像ハッシュ → ファイルの対応（重複を避ける）。
- `<バッチ名>/feedback.json`: 試合ごとの検出結果・確認画面の修正（正解）。`snapshots[].file` は、この `training/` からの相対パス。
- `<バッチ名>/images/<ハッシュ>.webp`: 画像（最大幅 1280・WebP）。

容量の目安: 1 バッチ（数試合）で数百 KB〜数 MB。リポジトリが重くなってきたら、データ専用の非公開リポジトリへの移動を検討する（D60）。
